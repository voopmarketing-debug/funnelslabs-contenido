Funnels LabsAntes de empezar

Qué es y qué vas a lograr

Una skill es un archivo de instrucciones que le enseña una tarea nueva a Claude. find-skills es la skill que busca las demás por ti: le dices qué necesitas, ella revisa el catálogo y te ayuda a instalar la más parecida.

Al terminar esta guía vas a poder

  • Pedirle a Claude, con tus propias palabras, una skill para una tarea (por ejemplo, responder WhatsApp o crear carruseles).
  • Instalar skills con un solo comando.
  • Revisar que una skill sea segura antes de instalarla.
  • Adaptar una skill a tu negocio sin perder tus cambios.

Requisitos

  • Claude Code instalado y con sesión iniciada. Esta guía instala la skill para Claude Code (en terminal, escritorio o tu editor).
  • Node.js instalado en tu computador. Incluye el comando npx, que usamos para instalar.
  • Una terminal: en Mac se llama Terminal; en Windows, PowerShell.
  • Conexión a internet.
¿No sabes si tienes Node.js? Abre la terminal y escribe node -v. Si aparece un número de versión, ya lo tienes. Si dice que no existe el comando, descárgalo gratis en nodejs.org.
Importante: esta guía es para Claude Code. Las skills instaladas así no aparecen en el chat de claude.ai en el navegador.

Funnels LabsPaso 1 y 2
PASO 1

Abre la terminal

  1. Mac: presiona Cmd + Espacio, escribe Terminal y presiona Enter.
  2. Windows: abre el menú Inicio, escribe PowerShell y presiona Enter.
  3. Verifica Node.js escribiendo node -v y Enter.
PASO 2

Instala find-skills

Copia este comando completo, pégalo en la terminal y presiona Enter:

npx skills add vercel-labs/skills --skill find-skills -a claude-code -g -y

Qué significa cada parte:

PartePara qué sirve
vercel-labs/skillsEl repositorio donde está la skill.
--skill find-skillsInstala solo esa skill.
-a claude-codeLa instala para Claude Code.
-gDisponible en todos tus proyectos, no solo en una carpeta.
-yNo te hace preguntas de confirmación.

Cuando termine, comprueba que quedó instalada:

npx skills list
Qué deberías ver: find-skills en la lista de skills instaladas.

PASO 3

Úsala: pídele a Claude lo que necesitas

Abre una sesión nueva de Claude Code (si ya tenías una abierta, ciérrala y vuelve a abrirla) y escríbele como hablas. No necesitas saber el nombre de la skill.

¿Cómo respondo más rápido mis mensajes de WhatsApp? Busca una skill que me ayude.
Busca una skill para crear mis carruseles de Instagram.
¿Hay una skill que revise la ortografía de mis textos?

Claude buscará en el catálogo, te mostrará las opciones y, si tú lo aceptas, te ayudará a instalar la que elijas.

Otras dos formas de buscar

DóndeCómo
En la terminalEscribe npx skills find [palabra], por ejemplo npx skills find whatsapp, y elige con las flechas.
En la webEntra a skills.sh: verás las más usadas y las nuevas, cada una con su comando de instalación.
Si Claude no la usa: pídeselo directamente: “Usa la skill find-skills para buscar una skill que haga X”.

PASO 4

Revisa la seguridad antes de instalar

Una skill puede indicarle a Claude que ejecute comandos y lea o modifique archivos. Es decir, puede hacer lo mismo que Claude hace por ti. Por eso, antes de instalar cualquier skill:

  • Entra a su página en skills.sh y revisa las auditorías de seguridad que se muestran.
  • Mira quién la creó. Prefiere autores y empresas que conozcas.
  • Fíjate cuánta gente la usa. Más instalaciones no es garantía, pero ayuda.
  • Lee su descripción. Pídele a Claude: “Léeme el archivo SKILL.md y dime qué hace y qué permisos usa”.
  • Desconfía de las que piden datos personales, claves o accesos que no necesitan.
Nunca pegues contraseñas, claves de API ni datos de tus clientes dentro de una skill.

Si te arrepientes

Puedes quitar una skill en cualquier momento:

npx skills remove find-skills

Y para ver cuáles tienes instaladas:

npx skills list

PASO 5

Hazla tuya, con tus reglas

Una skill genérica funciona mejor cuando conoce tu negocio. El proceso tiene tres pasos:

1 · Encuentra la skill

Usa find-skills y elige la que más se parezca a lo que haces.

2 · Pídele a Claude que la adapte

Copia este mensaje y completa lo que está entre corchetes:

Lee la skill [nombre de la skill]. Cópiala como una skill nueva llamada [nombre-de-la-skill]-[mi-negocio] y adáptala a mi negocio. Vendo [producto o servicio] a [tu cliente ideal]. Mi tono es [cercano, profesional…]. Reglas que siempre debe seguir: [tus reglas]. No modifiques la original.

3 · Guárdala con otro nombre

Por eso el mensaje pide una copia: la original se actualiza con npx skills update y, si editas esa misma, podrías perder tus cambios. Tu versión con otro nombre queda a salvo.

Prueba y ajusta: usa tu skill en una tarea real. Si el resultado no te convence, dile a Claude qué cambiar y que actualice tu versión.

Problemas comunes

Qué pasaQué hacer
“npx: command not found”Instala Node.js desde nodejs.org, cierra y abre la terminal.
La instalación dice que fallóRevisa tu conexión a internet y vuelve a pegar el comando completo, sin cortarlo.
No aparece en la listaEjecuta npx skills list. Si no está, repite el paso 2.
Claude no la usaAbre una sesión nueva y pídele que use find-skills por su nombre.
Quiero quitarlanpx skills remove find-skills
Quiero actualizarlanpx skills update
